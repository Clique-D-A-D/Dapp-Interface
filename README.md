🔗 Decentralized P2P Asset Rental System

A blockchain-based decentralized web application that enables users to rent and lend physical assets securely without centralized intermediaries or identity verification.

📌 Overview

The Decentralized Peer-to-Peer Asset Rental System is an Ethereum-based DApp that allows users to rent items such as tools, cameras, or equipment using smart contracts, crypto collateral, and on-chain reputation. Wallet addresses act as user identity, ensuring privacy and trustless transactions.

✨ Key Features

🔐 Wallet-Based Authentication

MetaMask login

No email, password, or personal data

🛒 Asset Marketplace

Browse assets in card-based layout

View rental price, safety bond, and owner reputation

📝 Asset Listing

Owners can list assets with description, fee, duration, and bond

🤝 Smart Contract Rentals

Rental agreements enforced automatically

Safety deposit locked during rental period

✅ Pickup & Return Confirmation

Mutual confirmation by borrower and owner

Late returns handled automatically

⭐ Reputation System

On-chain reputation tied to wallet address

Encourages honest behavior

📊 User Dashboard

View active rentals, listings, and rental history

Status tracking (Active, Completed, Late)
